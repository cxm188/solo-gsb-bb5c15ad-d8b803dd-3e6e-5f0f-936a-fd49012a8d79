🛡️ 许可证依赖冲突审计台

规范化依赖节点 · 支持 CycloneDX SBOM 导入 · 按许可证兼容矩阵计算传递约束 · 标出冲突的最短依赖路径 · 支持按包筛选与 JSON 导出 API 文档兼容矩阵

1. 上传或粘贴 manifest / CycloneDX BOM

依赖边方向：使用方 → 被依赖方；支持 packages / dependencies / edges 混合声明，也可直接粘贴或上传 CycloneDX JSON（自动识别 bomFormat / components / dependencies，按 bom-ref 还原依赖图）。

2. 历史审计 · 两次对比 · 复现包核验

⇄
对比为只读操作，不会创建新审计。节点按 包名@版本 配对， 许可证冲突/告警按「祖先节点 → 被依赖节点」配对，新增/消失/状态变化都会附上双方的最短依赖路径。
复现包（格式 audit-repro/v1）包含原始 manifest、保存的审计结果（未附着复核标记） 及两者的 SHA-256 摘要，可离线转交。核验为只读操作：按稳定键序列化重算两处摘要， 并用包内 manifest 重新调用分析器，剔除审计 ID、时间等运行元数据后逐项比对 节点、依赖边、冲突严重程度与最短路径——只有摘要与复算结果都一致才判通过， 否则指出首个不一致字段。核验不会创建审计或改动复核标记。

3. 根包退役预演 只读 · 不创建审计

根包 = 没有入边的包（没有任何其他包依赖它）。选择一条已保存的审计并勾选一个或多个根包后， 服务端沿 使用方 → 被依赖方 的边从剩余根包重算可达集合，展示因退役失去可达性的包、 仍被其他根包共用的包，以及随失联包消失的许可证冲突与原最短路径。 预演为只读操作，可反复调整勾选重新预演，不会创建审计或改动复核标记。

4. 单包许可证替换预演 只读 · 不创建审计

选择一条已保存的审计、一个包和候选 SPDX 许可证（内置兼容矩阵中的 14 个标识）后， 服务端仅替换该节点的许可证，沿原依赖图（节点与依赖边不变）重算传递兼容判定与最短冲突路径， 并按「祖先包 → 被依赖包」配对原结果与预演结果：新增、消失及等级变化的冲突都会附上两侧的最短依赖路径， 同时给出硬冲突数、告警数与冲突总数的净变化。 预演为只读操作，可反复更换候选许可证重新预演，不会创建审计或改动复核标记。

5. 未解析依赖补边预演 只读 · 不创建审计

选择一条已保存的审计后，中间下拉框列出源包仍存在的未解析依赖引用（源包 → 引用原文）； 再选一个现有目标包，服务端只在内存中补一条 使用方 → 被依赖方 的边并移除该未解析项 （其余节点、许可证与边完全不变），重算传递约束与最短冲突路径， 并按「祖先包 → 被依赖包」配对原结果与预演结果：展示新增及路径变化的冲突、 剩余未解析项与冲突数变化。引用或目标无效、补成自依赖或重复边会被拒绝（422）。 预演为只读操作，可反复更换选择重新预演，不会创建审计或改动复核标记。

7. 冲突与最短依赖路径

复核标记按「祖先节点 + 被依赖节点 + 双方规范化许可证」生成指纹，跨审计生效： 同一冲突在任意历史审计中重现都会带出同一条标记；许可证变更、标记过期或撤销后自动回到待复核。 每条冲突还可做最少断边分析：沿现有 使用方→被依赖方 图求让祖先包无法再到达被依赖包所需删除的 最少依赖边（并行路径、汇合路径与环均纳入计算，不只看当前最短路径），展示原最短路径、建议断边与断边后可达性。
